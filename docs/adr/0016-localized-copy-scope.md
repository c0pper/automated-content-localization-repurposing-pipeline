# Only per-Clip copy is localized

Each selected Target Language gets a localized Hook and social caption for each selected Clip. The LinkedIn and newsletter copy remain in the Source Language in v1. Localizing all copy was rejected because it multiplies translation cost and creates long-form assets that are not attached to a video. Localizing no copy was rejected because a localized Clip with a Source-Language caption is not a finished social asset.

**Consequences**: The Review Bundle carries Localized Clip Copy per Clip and language, and translation cost includes it. Long-form copy is source-language only; the Creator adapts it. Adding localized long-form copy later is additive and does not reshape the Clip assets.
